# Logistica-Inteligente-Modelos-Predictivos-de-Retrasos
Proyecto de Machine Learning para predecir retrasos en envíos. Incluye exploración de datos, visualizaciones logísticas y modelos (Random Forest, XGBoost, LightGBM). El modelo final, LightGBM binario con umbral 0.55, logra alta precisión y buen balance entre recall y F1-score
